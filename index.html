customCamera
AVFoundation · Metal · Core Media
The Problem
UIImagePicker's Limitations
The standard iOS camera API offers no manual exposure control, no raw format access, and no real-time custom shader processing — a hard ceiling for creative or professional use cases.
Discovery
AVFoundation + Metal Pipeline
AVCaptureSession exposes hardware-level camera controls — ISO, shutter speed, white balance — and Metal allows GPU-accelerated custom filter rendering at 60 FPS.
Build
Full Capture Pipeline
AVCaptureSession with custom AVCaptureVideoDataOutput, Metal fragment shaders for real-time filter previews, and manual hardware dial controls for ISO and shutter.
Decision Layer
Core Image vs Metal Shaders
Core Image is easier but introduces frame latency. Metal shaders run directly on GPU with no intermediate representation — the only path to true 60 FPS zero-lag preview.
Impact
60 FPS, Zero Latency
Delivered 60 FPS real-time filter rendering with manual hardware control — matching what professional camera apps achieve on iOS.
